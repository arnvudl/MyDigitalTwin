# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you find a vulnerability in MyDigitalTwin, please **do not open a public issue**.

Report it directly by email at **arnaudleroy20@gmail.com** with the subject line `[SECURITY] MyDigitalTwin`.

You can expect a response within 72 hours. If the vulnerability is confirmed, a fix will be prioritized and a new patch version will be released. If it is declined, you will receive a clear explanation.

Since this project handles personal GDPR data locally, any vulnerability related to data exposure or config file handling is treated as high priority.
